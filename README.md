🏃 Smart Sports & Healthy Lifestyle Coach

A web-based health and fitness application that helps users maintain a healthier lifestyle through personalized, rule-based recommendations and wellness tracking.

📌 Project Overview

The Smart Sports & Healthy Lifestyle Coach provides a single platform for users to assess their basic health indicators, explore exercise recommendations, plan weekly workouts, and access nutrition and hydration guidance.

🎯 Objectives

Assess basic health and lifestyle information.

Calculate Body Mass Index (BMI) and a rule-based health score.

Provide personalized exercise recommendations.

Support weekly workout planning.

Offer nutrition, hydration, and sleep-related guidance.

Track progress and support email reminders.

✨ Key Features

Health Assessment: Collects basic health and lifestyle details.

Health Analysis: Displays BMI and health assessment results.

Exercise Recommendations: Provides guidance based on user goals and preferences.

Weekly Plan: Helps users organize their exercise routine.

Nutrition Guidance: Provides general healthy-eating information.

Hydration: Supports hydration awareness and tracking.

My Progress: Displays available progress information.

Email Reminders: Supports configurable wellness reminders.

🛠️ Technologies Used


Python Application logic

Flask Web framework

HTML and CSS User interface and styling

Jinja2 Dynamic web templates

SQLAlchemy Database interaction

SQLite Data storage

APScheduler Scheduled reminder checks

SMTP (smtplib) Email notifications

Gunicorn Application server

Render Deployment and hosting

🏗️ System Workflow

The user opens the web application.

The user enters health and lifestyle information.

The application validates the inputs and calculates basic indicators.

Rule-based logic generates the available recommendations.

Assessment information is stored in the database.

The user views recommendations, plans, and progress.

Configured reminders can be checked and sent through email.
